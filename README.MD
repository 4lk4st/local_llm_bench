# LLM Experiments

**Гибкая система для проведения пошаговых экспериментов с Large Language Models (LLM).**  
Позволяет запускать базовые запросы к Ollama, добавлять RAG, структурированный вывод, оценку качества и тонкую настройку модели без изменения ядра проекта.

## 🔥 Особенности

- **Конфигурация в YAML** – параметры эксперимента задаются через `pydantic`‐модели.  
- **Пайплайны** – каждый эксперимент реализован отдельным пайплайном в `src/pipelines/`.  
- **Логирование** – `loguru` пишет логи в `data/experiments/<experiment_id>/logs.txt`.  
- **Экспорт результатов** – ответы сохраняются в Excel (`openpyxl`).  
- **Минимальные зависимости** – управляются через `uv`.  

## 📂 Структура репозитория

```
llm-experiments/
├─ data/
│  ├─ raw/                 # Исходные файлы (questions.xlsx)
│  └─ experiments/         # Результаты экспериментов
├─ src/
│  ├─ core/                # Работа с LLM и очистка ответов
│  ├─ pipelines/           # Реализации экспериментов
│  └─ utils/               # Вспомогательные утилиты (Excel I/O)
├─ configs/                # YAML‑конфиги экспериментов
├─ docs/                   # Документация
├─ tests/                  # Unit‑тесты
├─ run.py                  # Точка входа
└─ pyproject.toml          # Зависимости и хуки
```

## ⚙️ Установка

```bash
# 1. Клонируем репозиторий
git clone https://github.com/your-org/llm-experiments.git
cd llm-experiments

# 2. Устанавливаем зависимости через uv (Python 3.13+)
uv sync

# 3. Запускаем Ollama (локальный сервер LLM)
ollama serve
```

## 📋 Как запустить эксперимент

```bash
# Пример для baseline‑эксперимента
uv run run.py --config configs/baseline.yaml
```

- Конфиг задаёт модель, шаблон подсказки, пути ввода/вывода и дополнительные параметры.
- После завершения в `data/experiments/<experiment_name>/` появятся:
  - `results.xlsx` – ответы и метаданные.
  - `logs.txt` – полный лог выполнения.

## 🛠️ Добавление нового эксперимента

1. **Создайте конфиг** в `configs/` (см. `baseline.yaml` как пример).  
2. **Создайте пайплайн** в `src/pipelines/`, наследуя `BasePipeline` (если требуется дополнительная логика).  
3. **Зарегистрируйте пайплайн** в `src/pipelines/__init__.py`.  
4. Запустите `run.py` с новым конфигом.
