# LLM Experiments Architecture

## 🎯 Цель
Создать гибкую систему для пошагового улучшения качества ответов LLM с возможностью:
- Запускать "голую" модель (baseline) без изменений кода
- Применять техники (RAG, structured output, fine-tuning) через конфигурацию
- Версионировать эксперименты и сравнивать результаты

## 📂 Текущая структура репозитория
llm-experiments/
├── data/
│ ├── raw/ # Исходные данные (questions.xlsx)
│ └── experiments/ # Результаты экспериментов (автогенерация)
├── src/
│ ├── core/ # Ядро системы
│ │ ├── llm_client.py # Работа с Ollama API
│ │ └── response_cleaner.py # Очистка ответов (удаление think-блоков)
│ ├── pipelines/ # Сценарии экспериментов
│ │ ├── init.py # Регистрация пайплайнов
│ │ └── baseline.py # "Голая" модель (без RAG/промптов)
│ └── utils/ # Вспомогательные утилиты
│   └── excel_io.py # Чтение/запись Excel
├── configs/ # Конфигурации экспериментов
│ └── baseline.yaml # Базовый эксперимент
├── run.py # Единая точка входа
└── requirements.txt # Зависимости


## ✅ Реализовано (на текущий момент)
- [x] **Базовая архитектура**:
  - Конфигурация вместо хардкода (YAML)
  - Динамический выбор пайплайна через реестр (`PIPELINES`)
  - Автоматическое создание папок с экспериментами + копирование конфига
- [x] **Baseline-пайплайн**:
  - "Голая" модель без контекста и системного промпта
  - Поддержка любой модели из Ollama (qwen3:0.6b по умолчанию)
- [x] **Постобработка**:
  - Удаление `<think>...</think>` из ответов
- [x] **Работа с данными**:
  - Чтение вопросов из Excel
  - Сохранение ответов в отформатированный Excel

## ⚙️ Как запустить baseline
```bash
# 1. Запустить Ollama в отдельном терминале
ollama serve

# 2. Запустить эксперимент
uv run run.py --config configs/baseline.yaml

💡 Принципы разработки
KISS: Каждый эксперимент — новый конфиг + новый пайплайн (без изменения ядра)
Воспроизводимость: Все параметры сохраняются в папке эксперимента
Сравнение: Результаты разных техник хранятся в отдельных папках
